# 🎮 Rock-Paper-Scissors Game

A simple and interactive Rock-Paper-Scissors game built using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Live Demo

👉 [Play the Game](https://jasiiin999.github.io/rock-paper-scissors/)  
*(Make sure your repo name is `rock-paper-scissors` or update the link accordingly)*

## 🛠️ Technologies Used

- HTML – Structure of the page
- CSS – Styling and layout
- JavaScript – Game logic and interactivity

## 📁 File Structure

- `index.html` – Main structure of the game
- `style.css` – All styles and animations
- `script.js` – Game mechanics
- `assets/` – Folder containing:
  - `rock.png`
  - `paper.png`
  - `scissors.png`

## 🎮 How to Play

1. Open the game in a browser.
2. Click on Rock, Paper, or Scissors.
3. The computer makes a random move.
4. The result is shown with updated scores and messages.
